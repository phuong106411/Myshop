# MyShop Premium — React Frontend

Website bán hàng frontend-only bằng React + React Router + Vite.

## Chạy project

```bash
npm install
npm run dev
```

Mở địa chỉ Vite hiển thị trong terminal, thường là:

```text
http://localhost:5173
```

## Chức năng User

- Trang chủ premium
- Danh sách sản phẩm

- Tìm kiếm
- Trang chi tiết sản phẩm

- Đăng nhập / đăng ký
